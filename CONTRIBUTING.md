# Contributing

Thanks for contributing to Lamagotchi.

## Development
```bash
pnpm install
pnpm dev
```

## Ground Rules
- Keep features local-first and privacy-safe.
- Preserve level-based progression behavior.
- Add or update tests for gameplay and AI behavior rules.
- Use small, reviewable pull requests.

## Pull Request Checklist
- [ ] Typecheck passes
- [ ] Tests pass
- [ ] No regressions in onboarding/hatch/chat loop
- [ ] Docs updated when behavior changes
