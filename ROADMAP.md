# Roadmap

## Phase 0: Foundation (Week 1)
- Repository scaffolding and CI
- Tauri + React app shell
- Ollama detection and model list
- Base SQLite schema and persistence layer
- State machine skeleton and core stores

## Phase 1: Magic Vertical Slice (Week 1-2)
- Egg scene and hatch cinematic
- Creature canvas with speech bubble chat
- Level 1-10 word-cap enforcement
- Core stats and care actions
- XP + leveling + basic ability unlock logic

## Phase 2: Memory and Reflection (Week 2-3)
- Feed text/markdown ingestion
- Digesting state and outcomes
- Explicit memory approval flow
- Daydream state and daily reflection logs
- Memory viewer and skill journal

## Phase 3: Polish and Open Source Readiness (Week 3-4)
- Animation, shader, and UX refinement
- Performance pass for mid-range laptops
- Testing hardening (unit + integration)
- GitHub issue templates and contribution docs
- Demo script and release candidate

## Post-MVP
- Sentence/paragraph/assistant modes beyond Level 10
- Tool unlock framework with permission prompts
- Evolution paths (Scholar, Builder, Dreamer, etc.)
- Optional embeddings and richer memory search
- Community plugin ecosystem
